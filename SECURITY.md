# Security policy

## Reporting a vulnerability

Use GitHub's
[private vulnerability reporting](https://github.com/chocolatechipscookiecrumbles/AgentUsageMonitor/security/advisories/new)
for security or privacy vulnerabilities. Please do not open a public issue for a
vulnerability before a coordinated disclosure is agreed.

Never attach credentials, Keychain contents, authorization callback URLs, session
logs, raw provider responses, prompts, private source code, or unredacted
diagnostics. A small sanitized reproduction is safer and usually more useful.

This is a maintainer-run project and no fixed acknowledgement or remediation SLA
is promised. Reports will be evaluated according to impact, reproducibility, and
available maintainer capacity.

General bugs that do not expose security- or privacy-sensitive information belong
in the repository's bug-report form.
