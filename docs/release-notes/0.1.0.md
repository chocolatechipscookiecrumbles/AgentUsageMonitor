# Agent Monitor 0.1.0

Menu-bar usage monitor for **OpenAI Codex** and **Claude Code**: five-hour and
weekly limits, reset countdowns, threshold alerts, and a per-agent token monitor
read from records already on your Mac. Source is available under the MIT License.

This release rebuilds the menu so it fits its content, changes how Claude usage is
collected (passive capture first, never prompting on refresh), and fixes Settings
page switching. The disk image is `AgentUsageMonitor-0.1.0.dmg` and contains
`AgentUsageMonitor.app`.

## Install

1. Download and open `AgentUsageMonitor-0.1.0.dmg`.
2. Move `AgentUsageMonitor.app` to `/Applications`, replacing 0.0.1 if you have it.
3. Launch it — it lives in the **menu bar**. There is no Dock icon. The menu-bar
   item may appear in a different position than in 0.0.1.

## Requirements

- macOS 14 (Sonoma) or later.
- The Codex CLI and/or Claude Code, already signed in. This app adds no account
  of its own.
- No Python or other runtime. The app is now a single native executable.

## How Claude usage is read — please read before installing

Claude usage now comes from, in order:

1. **Passive capture.** A status-line snapshot Claude Code writes while you use
   it, if it is no more than two minutes old. No credential is read.
2. **Silent live fallback.** Claude Code's OAuth credential from your Keychain,
   read without ever showing a prompt.
3. **The last saved reading**, marked **Cached**.

macOS asks for Keychain permission only when you choose **Connect** or
**Reconnect Claude**. Ordinary Refresh, launch and background reads never prompt;
if access is unavailable, monitoring stays enabled and shows **Live fallback
unavailable**. **Force Read** (Settings → Agents → Claude → Claude /usage) takes an
explicit reading and may consume tokens from your Claude quota.

**Readings are only current while Claude Code is active.** Between sessions the
menu usually shows a Cached reading, marked with its age.

**Anthropic's Terms of Service do not permit a third-party application to reuse
Claude Code's credential.** The live fallback does. That is stated here, in the
README, and in the app's **Data & Privacy** page, so installing is an informed
choice; using it may put your Anthropic account at risk of enforcement. Turning
Claude off in **Settings → Agents** stops all Claude reads.

Codex usage is read from your local Codex CLI's app-server and carries no such
caveat.

## What's new

- **The menu fits its content.** The window is exactly as tall as the menu, with
  no leftover outline below it, and clicks outside it reach the app underneath.
  Switching between Codex and Claude no longer flashes duplicated or displaced
  content. Tall content scrolls without a visible scroll bar. The menu no longer
  takes focus from the app you are using, and the selected tab now uses each
  provider's color: blue for Codex, orange for Claude.
- **Settings page switching is clean.** Moving between Settings pages no longer
  shows a frame of duplicated text, and each page keeps its scroll position while
  Settings is open.
- **Model variants in Token Monitor.** Models keep their variant: GPT-6 Astra,
  GPT-5.6 Sol, GPT-4o Mini, GPT-5.1 Codex Max, Fable 5.1. Unfamiliar model names
  are shown as supplied instead of "Unknown model".
- **Claude, passive-first** (see above). Fresh passive data is labelled
  **Captured** and retained data **Cached**; both fresh passive and explicit
  `/usage` readings can trigger threshold alerts. Claude Settings shows
  usage-credit spending and a Claude Usage link for balance and resets.
- **Explicit consent before any provider work.** A fresh installation reads
  nothing from Codex or Claude until you choose Connect for that provider.
- **Single executable.** The Claude status-line bridge now runs inside the main
  app instead of a second bundled binary.
- **Codex Token Monitor** recovers when one local transcript is unreadable, and
  Codex token deltas are reconciled more strictly.

## If the new menu misbehaves

You can switch back to the 0.0.1-style menu. Run this in Terminal and relaunch:

```sh
defaults write com.david.codex-usage-monitor MenuHostLegacy -bool true
```

Undo it with `defaults delete com.david.codex-usage-monitor MenuHostLegacy`.
Please report what you saw.

## Known limitations

- **Claude readings go stale between Claude Code sessions** (see above).
- **macOS may ask for Keychain access again.** Occasionally the Keychain prompt
  reappears, or silent access stops working until you choose **Reconnect
  Claude** in **Settings → Agents → Claude**. Monitoring stays enabled in the
  meantime and falls back to passive or cached readings. The cause is still
  being diagnosed.
- **GitHub Copilot is not supported.** No personal-quota API has been verified
  for it; it is absent rather than broken.
- **Claude's weekly window is shared** with Claude chat, not Claude Code alone.
- **Keyboard shortcuts are fixed.** The four menu commands have fixed key
  equivalents, listed in **General**.
- **Claude credit balance and available resets are not shown.** No permitted
  automatic source provides them; **Open Claude Usage** links to the provider
  page.
