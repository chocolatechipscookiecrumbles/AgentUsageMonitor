Native menu versus window

Native menu: keep the root as a sequence of menu-compatible rows in Group. A SwiftUI Button renders as an inline command here.

Settings window: ordinary layout containers such as Form, Section, TabView, padding, and frames are appropriate.

Adding .menuBarExtraStyle(.window) intentionally changes the menu into a custom panel. Do this only when you want panel controls rather than native inline menu commands.

Modifier reading rule

Text("Last refresh")     // create a view
    .font(.caption)      // transform that view
    .foregroundStyle(.secondary)

Read SwiftUI top to bottom: create a view, then apply each modifier to the result above it. Indentation tells you which view receives the modifier.
